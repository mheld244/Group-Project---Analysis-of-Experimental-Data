# Group-Project---Analysis-of-Experimental-Data
This repository was created in the context of the course 'Case Studies in the Analysis of Experimental Data' and it contains all the code contributing to the project. From reading the data, to the analysis, and the figures.

In addition to the PDF file that explains our research objectives and steps performed, this repository contains four different folders:

1. Aalbers et al (2018): with the original dataset, and their main analysis.
2. Linear Mixed Models: R-code with respect to RQ1: “Does the day of the week have an effect on depression symptoms and social media usage?”
3. Moderation time of day: R-code with respect to RQ2: “Does the time of day have an effect on the interaction between depression symptoms and social media usage?”
4. Factor Analysis: R-code + figure with respect to RQ3: “What latent factor structure underlies the depression items used by Aalbers et al. (2018)?”


This project is a collaboration between Alexander, Adam, and Markus.
